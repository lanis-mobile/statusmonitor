# Historic official-status parser audit

Tested on 2026-10-25 against **50 Wayback snapshots / 300 service entries**,
covering 2023-03-30 through 2026-05-16. All snapshots returned by the bounded
CDX query were retrieved successfully (some required a second attempt).

## Scope and provenance

The supplied Markdown link has two different timestamps: its target is
[2023-03-30](https://web.archive.org/web/20230330025034/https://info.schulportal.hessen.de/status-des-schulportal-hessen/),
while its label refers to
[2024-01-03](https://web.archive.org/web/20240103065341/https://info.schulportal.hessen.de/status-des-schulportal-hessen/).
**Both were tested.** The corpus also includes the subsequent
[`-3` page](https://web.archive.org/web/20260516091714/https://info.schulportal.hessen.de/status-des-schulportal-hessen-3/).

The [CDX query](https://web.archive.org/cdx/search/cdx?url=info.schulportal.hessen.de%2Fstatus-des-schulportal-hessen%2A&output=json&filter=statuscode%3A200&filter=mimetype%3Atext%2Fhtml&collapse=digest&fl=timestamp%2Coriginal%2Cdigest&limit=500) selects HTTP 200 HTML captures with distinct CDX
digests, with a maximum of 500 results; it returned 50 captures. This is a test
of the returned corpus, not a claim about every capture ever made. No `-2`
page appeared in these results; Wayback's availability API also returned no
snapshot for that URL, so it was not tested.

All six services are checked in every capture. The corpus contains 60 restricted
service entries and 111 maintenance flags, including cases where both apply.

`test/fixtures/wayback/manifest.json` records each original URL, replay URL,
CDX digest, SHA-256 of the downloaded/decompressed response, SHA-256 of the
fixture, raw overview symbols, and literal expected statuses/maintenance flags.
Only the unchanged `.entry-content` HTML is kept in the fixtures; Wayback's
surrounding replay page and unrelated site navigation are excluded. Overview
expectations were extracted independently from the captured table cells and
stored as literal values, rather than generated by the Dart parser under test.

## Findings and fixes

- The legacy Login overview cell starts with `<a id="top"></a>` before the
  actual `href="#IdM"` link. Selecting its first anchor caused the Login status
  to become `unknown`, including during real outages. The parser now selects
  the first anchor **with an href**. Explicit regressions cover both an all-clear
  snapshot and the Login outage captured on 2024-09-13.
- Older update-history labels omit the colon (`Letzte Aktualisierung …`). The
  display previously treated this history as part of upcoming maintenance. Its
  history splitter now accepts either spelling and preserves the original text.
- Older all-clear / no-update notices vary in case, singular/plural and wording
  (`keine Einschränkung bekannt`, `Aktuell ist kein Update geplant`,
  `Aktuell sind keine Updates geplant`). These exact phrases are now recognized
  without hiding additional free-form notices.

- The compact summary previously mistook `02.01.` and `vsl.` for sentence
  endings. The January 2024 outage now retains its complete start/end window
  in the visible summary; the remaining current notice stays expandable.

There are dedicated assertions for the multiline January 2024 PaedOrg outage,
its SPH-Downloads notice, and the March 2023 scheduled maintenance dates.

## Reproduce without network access

Validation passed: 97 Dart tests, 54 frontend unit tests, 7 browser tests,
static analysis and the production build. The raw downloaded pages and the
presentation layer were additionally checked across all 50 captures / 300
services. Browser rendering was checked with actual parsed 2023, 2024 and 2026
payloads. The chart browser assertion now waits for painted canvas pixels to
avoid an unrelated timing race encountered during this run.

```bash
dart test test/official_wayback_test.dart
cd frontend && npm test -- src/lib/officialPresentation.test.ts
```

For a JSON audit of the stored pages or separately downloaded raw replay HTML:

```bash
dart run tool/check_official_archives.dart test/fixtures/wayback/*.html
```

Archive retrieval is only part of this audit; the production service continues
to fetch the stable official URL and enforce its existing HTTPS redirect policy.
No archived HTML is rendered in the browser. Text interpolation, filtering of
active subtrees, `nosniff`, and the Content Security Policy remain in effect.
